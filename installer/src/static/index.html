Підготовка

  1. Створіть сервер (дроплет) на DigitalOcean: Ubuntu 24.04, мінімум 1 GB RAM
  2. Скопіюйте IP адресу та root пароль з листа на email
  3. Спрямуйте ваш домен (A-запис) на IP сервера
Введіть коректну IP адресу
Введіть пароль
A-запис цього домену повинен вказувати на IP сервера
Введіть домен (наприклад admin.example.com)

Telegram бот

  1. Відкрийте @BotFather в Telegram
  2. Надішліть /newbot і дайте йому ім'я
  3. Скопіюйте токен (довгий рядок з двокрапкою)
  4. Надішліть /start вашому новому боту, потім відкрийте api.telegram.org/bot<TOKEN>/getUpdates — там знайдіть ваш chat ID
Токен має формат 123456789:ABC...
Ваш Telegram user ID (числове значення)
Chat ID — це число
Латиницею, без пробілів — буде назвою папки
Тільки латиниця, цифри, дефіс
