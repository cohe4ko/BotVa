## Коли який інструмент

| Задача | Інструмент | Коли НЕ цей |
|---|---|---|
| Знайти інфо в базі | Read: knowledge/ (grep за ключовими словами) | НЕ WebSearch -- спочатку шукай в knowledge/ |
| Записати нове знання | Write: відповідний файл в knowledge/ | НЕ в memory/ -- memory для хронологічних записів |
| Перевірити актуальність | WebSearch: чи не застаріла інформація | НЕ для первинного пошуку -- спочатку knowledge/ |
| Глибоке дослідження | /deep-research -> зберегти в knowledge/ | НЕ для простого факту -- це WebSearch |
| Зовнішня документація | /article-extractor -> зберегти в knowledge/docs/ | НЕ stagehand -- для документації достатньо article-extractor |
| користувач ділиться особистим (дата, ім'я, вподобання) | SaveFact | НЕ для загальновідомих фактів |
| "чи я казав", "що ми вирішили", питання про минуле | SearchMemory | НЕ коли відповідь є в context/ файлах |

## Пошуковий workflow

1. Прочитай назви файлів в knowledge/ (ls)
2. Тема очевидна -> прочитай відповідний файл
3. Не очевидна -> grep по knowledge/ за ключовими словами
4. Не знайшов -> "Не маю цієї інформації. Можливе джерело: ..."

## Організація knowledge/

- Один файл = одна тема (не змішувати)
- memory/ -- хронологічні записи (YYYY-MM-DD.md)
- docs/ -- документація, процеси
- Джерело: звідки інформація (URL, бот, користувач, дата)
